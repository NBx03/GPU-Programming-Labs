ШПАРГАЛКА ПО КОМАНДАМ НА КЛАСТЕРЕ (ЛАБОРАТОРНАЯ №4)
================================================================================

1. ПОДКЛЮЧЕНИЕ К КЛАСТЕРУ (с ноутбука через терминал PowerShell/cmd):
--------------------------------------------------------------------------------
ssh mag@cluster-gpn.nsu.ru


2. ВЫДЕЛЕНИЕ ВИДЕОКАРТЫ (переход на вычислительную ноду):
--------------------------------------------------------------------------------
# Вариант А: Переход на ноду с Tesla V100 (sm_70):
ssh gpuserv
# (или если через Slurm: srun -w gpuserv --pty bash)

# Вариант Б: Если gpuserv занят, очередь compclass (Quadro RTX 4000, sm_75):
srun -p compclass --pty bash

# Проверить, какая карта выделилась:
nvidia-smi


3. ПЕРЕХОД В РЕПОЗИТОРИЙ И ОБНОВЛЕНИЕ КОДА:
--------------------------------------------------------------------------------
cd ~/bazarov_gpu_labs || cd ~/GPU-Programming-Labs
git pull

# Настройка путей к компилятору nvcc (обязательно!):
export PATH=/usr/local/cuda/bin:$PATH
export LD_LIBRARY_PATH=/usr/local/cuda/lib64:$LD_LIBRARY_PATH

cd lab4


4. ЗАПУСК ВСЕХ ТЕСТОВ И БЕНЧМАРКОВ (512, 1024, 2048):
--------------------------------------------------------------------------------
# Если Tesla V100 (на gpuserv):
./run_lab4.sh sm_70

# Если Quadro RTX 4000 (на compclass):
./run_lab4.sh sm_75

# Ручной запуск конкретного размера (например, 1024):
./matmul --size 1024 --reps 5


5. ПРОФИЛИРОВАНИЕ ЧЕРЕЗ NSIGHT SYSTEMS (nsys):
--------------------------------------------------------------------------------
# Собрать профиль со статистикой в консоль:
nsys profile --stats=true --force-overwrite=true -o results/nsys_matmul ./matmul --size 1024 --reps 1

# Посмотреть уже сохраненный текстовый отчет nsys:
cat results/nsys_summary.txt | less


6. ПРОФИЛИРОВАНИЕ ЧЕРЕЗ NSIGHT COMPUTE (ncu):
--------------------------------------------------------------------------------
# Если препод просит запустить прямо на кластере:
ncu --set basic -o results/ncu_test ./matmul --size 512 --reps 1
# (Выдаст ошибку прав ERR_NVGPUCTRPERM — объясняем политику безопасности Linux ядра!)

# Как показать готовый отчет Colab (ncu_colab_details.txt):
cat results/ncu_colab_details.txt | head -n 45

# Сводный отчет с таблицей и анализом для сдачи:
cat NCU_REPORT.md
