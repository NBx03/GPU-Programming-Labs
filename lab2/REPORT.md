## Постановка
Программа накладывает фильтры на изображение: PNG (libpng) → массив → CUDA Device → фильтр на устройстве → хост → PNG.
Оценить накладные расходы на организацию вычислений на GPU по сравнению с CPU.

## Реализация
- **Форматы:** вход — любой PNG, приводится к RGB 8 бит; выход — RGB PNG.
- **Фильтры:** размытие по Гауссу (2D-свёртка (2r+1)², r=1..15, веса в `__constant__`), Собель (яркость `(77R+150G+29B+128)>>8`,
  результат серым), медиана 3×3 по каналам (сортирующая сеть из 19 обменов). Границы — replicate (clamp координат).
- **Варианты ядер:** `global` (чтение из глобальной памяти) и `shared` (тайл с гало в разделяемой памяти).
- **Корректность:** функции пикселя общие для CPU и GPU ([filter_common.h](filter_common.h)); сборка с `--fmad=false` /
  `-ffp-contract=off`. Ожидается 0 расхождений; программа печатает число расходящихся байт и максимальное отклонение.
- **Тайминги:** `cudaEvent` для этапов GPU (H2D, ядро, D2H), `chrono` для `cudaMalloc+cudaFree`, декодирования/кодирования PNG и CPU
  (1 поток и все потоки OpenMP). Медиана по повторам, один прогревочный запуск.
